# Diseño de referencia

`oficina-diurna/referencia.png` y `referencia.html` son la referencia visual aprobada para la primera versión: vista isométrica diurna para tablet Android en horizontal, escena a pantalla completa y panel lateral único.

`DESIGN.md` define colores, tipografía, radios y componentes ("Atelier Engineering Studio"). Es la fuente de los tokens de la interfaz.

La escena del HTML está construida en SVG con elementos independientes por mueble y personaje; puede servir de punto de partida para la escena real.

El contenido técnico de la referencia (subestación 66 kV, valores de ajuste, nombres de archivo, nombre "Carlos M.") es ilustrativo. No debe trasladarse al código como dato. Los ajustes pendientes sobre la referencia están en `docs/08-tramo-1.md`.

Generado con Google Stitch; las versiones anteriores en tema oscuro quedaron descartadas.
