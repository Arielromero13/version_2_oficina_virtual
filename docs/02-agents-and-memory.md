# Agentes y memoria selectiva

## Catálogo de capacidades

Cada agente guardado es una ficha reutilizable, no un proceso que permanece activo. La ficha puede contener:

- nombre y especialidad;
- propósito, instrucciones y estilo de trabajo;
- tareas para las que sirve y límites conocidos;
- proveedor/modelo recomendado y alternativas compatibles;
- herramientas y scripts vinculados;
- caso de origen, versión y archivos de referencia permitidos;
- evaluación breve de su desempeño y condiciones de reutilización.

Los roles del repositorio anterior, como especialista de dominio, investigador normativo, revisor técnico, integrador y auditor, pueden servir como perfiles iniciales. El Orquestador puede combinar varios perfiles o generar uno temporal para un encargo.

## Ciclo de un agente

1. El Orquestador interpreta el encargo y define las capacidades que hacen falta.
2. RR. HH. busca perfiles, herramientas y scripts relacionados.
3. Ariel revisa el equipo propuesto cuando el impacto, costo o riesgo lo amerita.
4. Cada agente recibe solo su mandato, contexto y archivos relevantes.
5. El agente entrega resultados, archivos, limitaciones y preguntas al responsable del encargo.
6. Al cerrar el trabajo, RR. HH. puede recomendar guardar una ficha, script o aprendizaje reutilizable.
7. Ariel decide si ese material se conserva y si puede emplearse en otros encargos.

## Agentes recuperados como colaboradores

Una ficha archivada puede volver a participar en un encargo. El Orquestador especifica qué conocimiento, método o herramienta necesita de ella. El agente recuperado colabora en esa tarea sin borrar ni sustituir al agente principal.

Cuando se trae un script, el sistema muestra origen, versión, propósito, entradas esperadas y limitaciones. No ejecuta código archivado de manera automática si su efecto no está entendido y autorizado.

## Qué guardar y qué no

Guardar elementos que puedan ahorrar trabajo: prompts depurados, métodos, scripts, criterios de revisión, estructura de archivos y decisiones útiles. Mantener vínculo con su fuente y fecha.

No archivar por defecto todo el chat ni datos de clientes, plantas o campañas. El usuario elige qué material queda disponible para reutilización. La biblioteca permite desactivar, versionar o eliminar recursos que ya no aplican.

## Recuperación económica

La búsqueda empieza por metadatos y resúmenes cortos. Solo se carga el contenido completo cuando una ficha parece pertinente y el usuario o el Orquestador confirma que se usará. No se mantienen agentes activos ni se vuelven a leer carpetas completas en cada solicitud.
